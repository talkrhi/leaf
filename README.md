# Leaf
(Lazy Easy And Free) Bloging software.
<hr>
<br>
This is <b>Leaf</b> a simple, fast and easy to use blog server.

<br>
Why? I hated having every other blog program ever, so with a lot a lot of sleep deprivation, and writing C# for the first time in months. WE HAVE LEAF.

it's super easy to setup and get running which in the next part I'll show you how to do.


## Install guide
<hr>
<br>
I don't recommended using Windows for this, so these steps mainly apply for Linux and macOS.
<hr>
<br>
Dependencies:
<br>
C#/.net: [Click here](https://dotnet.microsoft.com/en-us/download)
<br>
<br>
NPM/Node.js: [Click here](https://nodejs.org/en)
<br>
<br>
Steps (a lot of steps)
<br>
<br>
Cloning
<br>
<br>

```bash
git clone https://gitlab.com/talkrhi/leaf.git
```
Build web app.
<br>
```bash
cd client && npm run build
```
Build actual server
<br>
```bash
cd server && dotnet build && dotnet run
```
<br>
then from there you just vist the page it provides and set up you're server.
